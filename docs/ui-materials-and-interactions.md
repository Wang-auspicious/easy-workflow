# 界面材质与交互细节

所有节点继续使用布局版本 7 的 240 × 112 尺寸。新增的 `ui/src/styles/materials.css` 是最终材质层，在组件样式之后加载：统一侧光、边缘高光、分层投影、状态底栏与角色图标色。分区底板、工具栏、详情、对话、工作流库和设置使用同一套颜色与层次。

悬停只改变边缘和阴影，不移动节点或连接端口。只有按钮有短促按压反馈；减少动态效果、减少透明度和提高对比度的系统偏好有对应样式。没有新增依赖或外部图片资源。

## 使用体验

- 工作视图最低 80% 缩放，小窗口通过平移查看；全图仍可用 F 或“全图”按钮打开。顶端操作和底部导航保留空间。
- 画布使用裁剪而非原生滚动，避免聚焦节点或调整窗口后，浏览器把浮动工具栏一起滚走。
- 图层菜单支持方向键、首尾跳转、Esc、点击外部收起与焦点返回。关闭菜单不会顺带关闭工位详情。
- 提示气泡同时支持鼠标和键盘，测量后避让窗口边缘；移开、滚动、点击或 Esc 可清除。
- Ctrl+K 从群组或对话列表直接打开主调度并聚焦输入框。切换会话、收起再展开均保留草稿、送达方式和未确认消息的请求身份。
- 对话栏拖动直接跟随指针，取消手势会清理监听；也可聚焦分隔条后使用方向键调整宽度。
- 输入框跟随实际宽度重新计算高度，修复从收起状态展开时，空输入框被撑到最大高度的问题。
- 详情位置依据真实卡片宽度计算，限制在可用区域内；既有消息点击白屏修复和局部错误边界保留。
- 待人工审核按钮从运行统计按钮内部移出，消除嵌套按钮。

## 最新版讨论与等待状态

v2 字段质疑、答复与讨论的底层行类型也叫 `note`。旧 UI 把它们与普通工位播报一起过滤，导致群组被藏入安静列表、未读为零、正文也看不到。现在按真实字段事件显示讨论，进展仍由独立开关控制；自动完成声明继续留在证据链中。

节点底栏恢复模型、预算、讨论、退避、资源、主调度等实际等待原因。超过两种时显示额外原因数量，悬停可读完整计数；没有放大或挤压卡片尺寸。

## 验证入口

- `npm run typecheck`。
- `npm run test:ui`：45 项；字段预览与未读统计回归补入现有 `rooms.test.ts`。
- `node --test test/geometry.test.ts`：14 项，覆盖尺寸、重叠、连线与折叠线路。
- `node ui/test/api-browser.mjs`：连接与保存，加上菜单、提示气泡、快捷键、草稿、缩放窗口、拖动宽度、减少动态效果。
- `node ui/test/chat-browser.mjs`：真实发送入口、失败重试身份、切换会话、恢复和紧凑输入框。
- `npm run test:ui:nodes`：v1/v2 逐条点击结构化与历史消息，包含故意损坏记录的局部错误隔离。
- `node ui/test/workflows-browser.mjs`：真实配置、建线、投料、产物哈希、来源接入和空白工作流编辑。
- `node ui/test/history-browser.mjs`：35,402 条事件、600 次尝试的历史、报告和回放。
- `node ui/test/rooms-browser.mjs` 与 `--v2`：真实运行日志中的跨线往来，以及隔离的 v2 字段讨论、证据链、进展开关、经验删除和等待状态。

浏览器回归已从旧的双栏群组和“规格”按钮定位更新为当前对话列表与“说明”页签，保留数据、失败恢复和实际回执断言。运行截图写入忽略目录，不再覆盖历史验收文档。

视觉检查覆盖 2000 × 1240、1440 × 960、1366 × 768；34 个展开节点尺寸一致、标题无溢出、悬停几何不变。截图与验证数据均来自隔离项目，不表示实际生产成果。

桌面包 `EasyWorkflow-polish-win-x64` 已通过独立原生验收 25/25：启动、内置浏览器、原生截图、结束轮次、重启持久化、只读保护和后台录屏，未捕获渲染异常为零。包内应用为 26.8 MiB，含 Electron 总计 346.7 MiB；旧版包保留。
