# Easy Workflow v0.3.0 · 2026-10-17

## 新增

- **主调度可以自己创建并运行新线路。** 从目标出发编写节点、连线、角色和输入输出契约，保存草稿，按校验错误修改，用真实执行器隔离试跑；通过后启用同一版本并正式投料。支持并行汇合、条件分支、独立审查、有界返工和跨线交接。既有内置线及用户安装包的结构改动仍保留原决策入口。
- **新增草稿增量修改和交付核验。** `workflow_edit` 只改需要调整的节点、连线或字段，并校验版本；`workflow_result` 检查真实文件的归属、字节数和 SHA-256。重启后可找回草稿、试跑回执与正式产物。
- **接通其余预置业务线。** 组件、图鉴反哺、Skill / DESIGN.md、科研绘图、PPT、图像处理均有实际执行器及输入契约。图鉴消费组件的真实发布结果，Skill/PPT 保留原件，科研绘图需要真实数据或可复现代码。
- **新增真正的新对话和历史对话。** `/new`、`/clear` 重置模型上下文，保留历史、工具回执及流水线任务；`/history` 查看和搜索旧对话，`/clear-input` 只清输入框。重启后会话边界仍有效。
- **新增主调度的精简审计能力。** `manual_review` 返回当前阻塞、已保存证据、可重建的页面来源和剩余修复次数。固定清单可以等待结果并核对数量，旧失败描述不会覆盖新的成功状态。
- **新增 v1 预算交接续接。** `resume_handoff` 保留已付费的会话，从原工位继续；每工位最多续接两次，并保留时间与 token 上限，不消耗截图纠错次数。
- **新增技术故障的有界检查点续接。** 主调度可以明确选择任务、说明已修好的程序或环境原因，从原失败工位恢复。跨后续任务每工位最多两次，原证据和返工次数保留；登录、验证和真正的用户取舍仍需用户处理。
- **README 加入真实截图与 30 秒演示。** [1080p MP4](https://github.com/Wang-auspicious/easy-workflow/releases/download/v0.3.0/EasyWorkflow-v0.3.0-demo.mp4) 来自 v0.3.0 桌面程序的连续录制，展示真实模型创建并执行过的工作流、工位消息和交付链；这是已完成结果的界面导览。

## 改进

- **节点统一为 240 × 112。** 来源、程序、Agent、汇合与库存卡片尺寸一致。增加边缘高光、分层投影和清楚的状态底栏；悬停不移动连线端口，按钮有按压反馈。
- **细化整个工作台的交互。** 图层菜单支持键盘与焦点返回；提示气泡避让边缘；对话栏可以拖动或用键盘调整宽度。减少动态效果、减少透明度和提高对比度的系统偏好有对应样式。
- **对话侧栏更接近日常 Agent 会话。** 命令菜单、Tab 补全、方向键选择和发送按钮使用同一条命令路径；增加模型状态、复制、再次编辑、长消息展开、回到最新及可展开的中断原因。切换群组或收起侧栏保留草稿。
- **人工审计只优先展示需要人决定的事。** 技术问题分到“Agent 待修复”，页面一次聚焦一个问题，相关证据优先，完整原始记录按需展开。暂存意见与稍后处理在当前应用会话中保留。
- **区分自动返工与明确授权的纠错次数。** 诊断直接返回剩余额度，避免把历史总轮数当成当前上限。额度耗尽仍是技术阻塞，不能自动变成人的内容判断。
- **浏览器提供可执行的取景信息。** 主调度能读取真实页面的标题、媒体、控件、位置与唯一 selector，并把取景、上下位置和普通弹窗关闭传给摄影程序；不读取密码或字段值。
- **业务线交接更完整。** 修正带查询参数的素材入口识别、v2 业务数据传递、组件自动续批及组件发布后的图鉴交接。

## 修复

- **修复点击工位消息后整页白屏。** 兼容结构化字段与历史记录，异常详情被限制在局部面板，画布继续可用。
- **修复 `/clear` 只清输入框、点发送无效的问题。** 回车、菜单和发送入口一致，未知命令有解释，不会误发给模型。
- **修复摄影重拍后，审查会话仍只看到旧图的问题。** 新输入会附带当前图片字节；仅真正续接未完成的同一请求时复用已有图片。
- **修复有效提交被迟到的预算统计改成强制交接。** 已通过契约的提交不再因为结算顺序而重复审核、重复计费。
- **修复旧记录缺少页面来源及派生字段的问题。** 复用保存的截图和录屏重建结构，再经过原终审与发布闸门。
- **修复一组真实页面取景问题。** 包括重复 HTML id、定位文字中的引号、工具区位于 aside、懒加载图片尚未滚入视口、弹窗标题在页脚重复，以及桌面关闭控件使用 SVG 的情况。保留实际页面和独立截图审查。
- **修复错误取景命令污染当前状态。** 跨站目标在执行前拒绝；超出纠错上限不覆盖原失败，也不取消已经排队的工作。已在途或已完成的任务默认跳过重复纠错。
- **修复旧重试父任务重复挤占待审队列。** 后续任务的实际结果可被追踪，同时保留旧记录及独立的跨线任务。
- **修复新浏览器标签刚建立时立即读取失败。** 短暂等待同一真实目标出现，不改读另一个标签。
- **修复 v2 字段讨论被误当普通播报隐藏的问题。** 质疑、答复与讨论重新计入群组展示和未读状态。
