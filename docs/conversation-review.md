# 对话侧栏与人工审计改进

## 命令与上下文

此前 `/clear` 的实现只清空输入框，点击发送还会绕过命令处理。本次统一命令入口，回车、命令菜单和发送按钮使用一致的行为。

- `/new`、`/clear` 开启新对话，真实重置模型上下文。历史消息、工具回执和流水线任务保留；执行中的回答先停止。
- `/history` 打开可搜索的历史对话；旧对话只读，可返回当前对话继续工作。
- `/clear-input` 仅清空输入和附件；`/help` 展示可用命令，`/model` 打开实际模型设置。
- 既有状态、报告、停止、继续、暂停、恢复和补充命令继续可用。Tab 补全，方向键选择，Enter 执行；未知命令显示解释，不发给模型。
- 新对话的请求身份在失败重试和收起侧栏后保留。重复的旧请求回执不能中止后来的回答。

会话边界以 `chat.session` 事件持久保存。模型历史只读取当前边界后的相关聊天事件；新对话不再扫描并解码整份生产日志。重启保留边界；若在记录边界后、记录新检查点前崩溃，旧检查点不会恢复进新对话。项目历史本身不删除。

侧栏增加可见模型状态、新对话与历史入口、复制消息、再次编辑、长消息展开、回到最新以及可展开的中断原因。批量收起工具后，单张工具卡仍能独立展开。

## 人工审计

页面按“选一件 → 看问题 → 看相关证据 → 决定下一步”组织。

- 待审队列可搜索，按截图与页面、事实与许可、内容与分类、连接与执行等问题筛选。
- 首屏展示简短问题；已知内部字段诊断转换为普通说明。完整原始原因和执行记录按需展开，不删减底层证据。
- 相关截图优先显示，可切换证据、放大原图、播放录屏。
- 退回工位从条目所属线路选择；修改意见提供可编辑的快捷选项，也可附上任务向主调度求助。
- 稍后处理和未提交意见保存在当前应用会话中，切换条目或页面不会丢失；关闭应用后不保证恢复这些尚未提交的界面草稿。
- 仅实际成功的回执才推进下一件；失败保留意见并显示错误。没有增加强制发布或绕过审查的操作。
- 修正了事件投影原地修改 token map 后，待审列表缓存不能及时更新的问题。
