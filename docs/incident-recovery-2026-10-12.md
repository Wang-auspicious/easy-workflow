# 模型中断、证据交接与批量恢复

## 现场与判断

检查原始运行日志与候选恢复记录后，确认该轮领取 41 件、0 件发布；最新状态为 36 件停放、1 件排除、1 件待人工、3 件在途，轮次已暂停。主调度把 `network_connection` / `network_timeout` 全部解释成网站网络问题不成立：多数错误实际发生在阅读、事实核验及审查的模型请求边界。

单 Agent 与流水线的差异在于交接数量和恢复方式。一次模型中断在旧流水线中会清掉工位对话，再消耗整件网站的恢复预算；停放又释放投料窗口，于是继续领取新网站。多个层级的 SDK / 工位 / 批次重试把共享服务故障放大成大量站点失败。仅凭这些历史通用错误，不能断言当时是代理、服务商负载还是某个网站造成的。

同时发现两个独立的实现缺陷：分类 Agent 看到了卷宗中的导航/页脚链接，但引用校验没有包含这些内容；事实工位补读完整页面后，校验仍优先使用较短的初始摘录。程序可能拒收有出处的答案。旧引用检查只比较前 80 个字符，还可能接受编造的尾句。

浏览器存在明确的泄漏路径：后台任务的 `window.open` 被登记为持久用户页，不能随任务租约释放。另有租约超时后的迟到回执、注意事项检查无限等待，以及关闭原生视图未移除父视图的问题。历史记录不足以确定这一路径造成了当时全部多余标签，但该路径已经通过回归覆盖。

恢复原批次副本时，进一步复现了并行分支丢失：截图审查失败取消了正在执行的事实审查；重试只排入截图审查，完成后无人再排入事实审查，汇合节点永远等不到另一边，系统误转人工。恢复现在重建所有尚未完成且前置条件就绪的分支；已经完成的工位仍复用。旧数据中只有能证明存在遗漏分支的系统误转人工记录才迁回可恢复候选，真实内容拒收和人工决定保持。

## 修复后的契约

- **区分故障来源。** 模型连接/超时/限流标记 `model_transport`；凭据/额度标记 `model_unavailable`。浏览器和站点错误继续使用各自标签。历史记录按实际失败边界迁移，保留审计；模型错误不再消耗网站修复额度。
- **共享服务故障停止投料。** 托管目标持久保存 `modelCircuit`。冷却后只允许一个真实工位恢复；通过后再放行。最多三次自动验证，仍失败就保留提醒和检查点。重启不解除保护，暂停不会被当成重试授权。浏览器无余量时也不继续补新料。
- **实际请求统一限流。** 工位、程序内看图/选页助手和主调度共用模型请求队列，默认最多 2 个在途请求，可用 `FACTORY_MODEL_REQUESTS` 配置（1–8）。工位数不等于 HTTP 请求数。SDK 内部重试关闭，由有上下文的工位续答和批次恢复负责。排队不消耗单请求截止时间；取消会移除等待者。
- **保留中断位置。** 模型断连后的工具回执、已读证据和对话保存到项目 `work/agent-sessions/`。重试时校验模型、角色版本、输入及 schema；匹配才续答，不重复已完成的页面读取。修改了输入/角色时重做该工位；其他工位检查点继续复用。
- **体检不能空答通过。** 输出截断、只有内部思考或没有完整 `OK` 都不能算健康。轻量体检仅允许真实工位试恢复，不能直接解除批量保护。模型出口错误保留脱敏的主机与底层错误码。
- **校验真实证据。** 卷宗展示与引用检查使用一致的文本；工具读取按工位隔离，并保留同一 URL 的多个版本。完整引用逐段核验，不能用前缀掩盖编造。事实工位交出实际引用来源供后续复核；工具结果保持合法 JSON，不从中间截断。
- **浏览器归属与清理。** 任务弹窗不能转成用户页。迟到的桌面租约立即释放；检查超时有上界且合并重复请求；同源相同类型的登录现场去重；取消和重复关闭幂等。真实登录、验证及用户页仍保留。等浏览器容量的任务保持排队，不记为站点失败。

## 验证

回归覆盖断连续答、跨工位尝试保存工具回执、共享故障停止投料、三次恢复上限、暂停/重启、完整引用与隔离、空答体检、后台弹窗、原生浏览器崩溃、迟到回收和取消。真实数据与原始验收日志保存在被忽略的本机 artifacts 目录，不进入公共仓库。

真实新任务 Lucide 已完成侦察、阅读、独立分类、三角色采集、事实/截图/文案审查、组装、终审和发布闸门，产生 `lucide.dev.json`。终审遭遇一次请求超时后原地续答成功。使用的是验收时用户当前 Pi 模型 Muse Spark；这不能证明此前的 DeepSeek 服务在故障时正常。

原 41 件批次另做一致性副本，验证 Plasmic 和 Humbleicons 从失败工位继续；原项目保持暂停。最终运行结果见后续验收记录。外部服务、真实登录限制和内容质量问题仍可能发生；验收标准是明确定位、正确恢复和真实产出，而不是把所有错误显示为成功。
