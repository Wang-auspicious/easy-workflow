## 本批变更

- **实际活动记录。** 模型请求、首字等待、输出、每次工具调用分别保存开始与结束事件。并行工具保留各自区间；取消也关闭已发生的区间。报告按指定轮次、工位读取，不用新一轮数据补历史。删除工位后，历史用量和等待仍保留，不基于不存在的配置生成人数建议。
- **耗时色条接入真实数据。** 维持现有面板布局，改用实际区间绘制耗时色条，悬停显示毫秒级时间与重叠活动。并行工具按并集计算单工位墙钟时间；多工位工作时间可相加。旧记录明确标记比例估算，闭源适配器未提供的模型区间保持未知；Token 色条仍为比例估算。
- **模型恢复保留上下文。** 瞬断后保留同一会话已完成的工具消息，只移除失败的末尾回答，再继续一次；续接共享原始超时与取消信号。多次连接失败才退回候选，已发生用量与活动均保留。
- **真实开跑体检。** 使用已配置模型完成一次经过认证的最小推理，输出上限 64 tokens；供应商首页可达不能代替模型可用。外网探测有备用目标；请求超时被取消，错误中原始及转义后的凭据均脱敏。
- **跨轮次案卷。** `cases/<item>/CASE.md` 与 `case.json` 由完整日志生成，保留动作、证据、审查、纠错与遗留问题。重启重建，退出前刷新；只读项目不生成文件。两个文件分别原子替换并共享摘要，不宣称它们是跨文件事务；中断后由重建恢复一致。
- **经验验证不串任务。** 经验候选的注入绑定具体 token、attempt、工位与条目；同站点并行任务不能相互借用验证证据。跨轮次案卷中的数组快照也不会被后续纠错改写。
- **浏览器自动恢复。** 页面或浏览器进程损坏先作废受影响的 attempt，再从检查点重排，最多自动恢复两次；保留用量、证据和旧产物。停止时不重新派工。桌面模式仅回收损坏的 Agent 页面，保留用户页及需要验证的页面。
- **浏览器名额等待。** HTTP 未取得正文时，侦察等待可取消的浏览器名额，最多 60 秒；资源容量超时归为系统问题，不冒充网站不可用。工具取消或创建页面失败均释放名额。
- **截图检查绑定选中舞台。** 无关的空 iframe 不再拒绝正常组件，旁边有内容的 iframe 也不能掩盖选中舞台的空白；等待与检查使用同一个 DOM 元素及其可见子 frame。异步组件最多等待 45 秒，支持导航、延迟挂载与取消；超时仍拒收，质量阈值不变。
- **目录语义复核。** 阅读员和截图审查员明确区分组件预览与客户整站展示。程序媒体计数不能独自证明图里展示的是可取得组件，也不能把一个组合组件中的装饰拆算为多个组件。
- **截图前再次检查遮挡。** 异步组件等待和滚动拼接后，复用既有 Cookie 处理规则，逐帧清理晚出现的遮挡；不接受 consent，新出现的登录或验证墙仍拒收并保留。
