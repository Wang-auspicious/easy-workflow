# 分流员（程序工位）

> 执行身份：确定性程序，不调用模型。

## 做什么

按材料类型把候选交给正确的业务线：

| 材料 | 去向 |
|---|---|
| DESIGN.md、SKILL.md 等文件链接 | Skill / DESIGN.md 线 |
| `.pptx`（含下载查询参数）或明确指定的 PDF deck | PPT 线 |
| 明确提供组件页面或 route=components | 组件入库线 |
| 带 figure 真实数值或代码复现输入 | 科研绘图线 |
| 带 effect 变换和真实原图 | 图像处理线 |
| 其余网站 | 策展线 |

业务输入在进入下游前校验；缺少数值、无效图像参数或异站组件页面会明确报错，不能编造输入。组件发布后自动反哺图鉴，不绕过组件审查直接投递图鉴。分不清时交给策展线，由侦察员和分类员读站后再判断；普通 PDF 可能是论文，不能仅按扩展名当演示文件。
