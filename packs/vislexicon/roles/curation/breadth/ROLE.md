# 目录摄影（程序工位）

> 执行身份：确定性程序，不调用模型。

## 拍什么

拍一眼能看出"有多少、有什么"的页面：

- 组件源：首屏有一批渲染出来的预览的组件目录；
- 合集：作品网格；
- 素材站：素材网格；
- 设计规范：基础规范页（色彩 > 字体 > tokens）；
- 工具：功能或案例页；
- 知识站：文章列表。

## 选页顺序

1. 站长或 Agent 通过"指定采集页"给出的页面；
2. 审查员要求"重新取景"时的原页面（保留地址，只重新取景）；
3. 阅读员拍摄单里的首选页和备选页；
4. 预览规则打分的候选；
5. 都不合格时，让模型从编号列表里选一个（needsPick），最多两次。

**第二跳：** 进入目录区后，侧栏常会展开出更合适的页（比如 Carbon 的 Foundations → Color）。分数明显更高时会换过去。

## 情况与处理

- **候选页 404：** 只说明这个子页面失效，不代表整站无效。换下一个候选，不能删除整个网站。
- **相同截图：** 和首屏几乎一样（感知哈希距离 ≤ 6）就拒收，换一页。
- **组件源的目录预览不足：** 当前取景内必须有至少 4 个渲染预览；只有名称列表、预览在画面外或计数缺失都不能放行。程序对首选页和第二跳同样检查，将计数随截图保存；截图审查不能覆盖这条门禁。
- **Storybook：** 保留 `path` / `id` 等路由参数，不能把它们当跟踪参数删掉。
- **全部候选都不合格：** 以"需要重新选页"退回候选库。站长或 Agent 可以用"指定采集页"给出页面，从这一站继续，已有成果保留。
