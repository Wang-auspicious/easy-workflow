# 首屏摄影（程序工位）

> 执行身份：确定性程序，不调用模型。

## 拍什么

拍真实首页的第一屏（1280×800 视口），回答"它是谁"。阅读员注明首页不合适时（登录墙、只有 Loading、信息太少），改拍他指定的替代页。

## 怎么拍

1. 打开页面，等待渲染静默。
2. 只点"拒绝 / 仅必要"Cookie，绝不点"接受"；没有拒绝按钮的同意条只在截图里隐藏。
3. 隐藏吸顶栏和聊天气泡。
4. 截首屏，并检测动效优先（滚动被接管、画布盖住首屏）。动效优先的非组件类站点改走录屏。

## 拒收与处理

| 拒收原因 | 处理 |
|---|---|
| 大块单色（首屏动画没渲染） | 轻推滚动、等 4 秒重拍一次；4 秒后画面不变，说明是真实的大色块设计，放行 |
| Cookie / 同意弹层盖住超过 25% | 不合格 |
| 空白、只有 Loading | 不合格，交给审查员按"等待渲染"处理 |
| 登录墙、验证页 | 失败，保留页面，亮红灯 |
| 证书错误 | 失败，亮红灯；不跳过校验 |

截图成功不等于内容合格。内容是否合格由截图审查员判断。导航失败和画面质量问题分开记录。
